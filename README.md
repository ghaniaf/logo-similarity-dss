## Akses Dataset

### Logo-2K+ (Dataset Pelatihan)
- **Sumber:** https://github.com/msn199959/Logo-2k-plus-Dataset
- **Subset yang digunakan:** Kategori Food
- **Setelah data cleaning:** 214 brand, ±10.689 citra

### METU Trademark Dataset v2 Only Query (Dataset Evaluasi)
- **Sumber:** http://service.metu.edu.tr/trademark
- **Paper:** Tursun et al. (2017) — A Large-scale Dataset and Benchmark 
  for Similar Trademark Retrieval
- **Subset yang digunakan:** Query set (417 logo, 35 grup kemiripan)

### PDKI Indonesia (Database Demonstrasi)
- **Sumber:** https://pdki-indonesia.dgip.go.id
- **Jumlah:** 6.698 logo dari 45 kelas NICE (2024–2026)
- **Link hasil scrapping:** https://drive.google.com/drive/folders/1g657euAOltfT420eVTvXVfl2EmW4OYd9?usp=sharing
- **Catatan:** Data dikumpulkan melalui akses publik PDKI. 
  File embedding tersedia di Google Drive peneliti 
  (dapat diminta melalui kontak di bawah).
